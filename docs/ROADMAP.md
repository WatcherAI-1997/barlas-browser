# Roadmap

The roadmap is directional. Security fixes take priority over feature work.

## 0.1 — Browser foundation

- [x] Custom BARLAS shell
- [x] Chromium tabs and navigation
- [x] Google search from the address bar
- [x] Persistent profile and downloads
- [x] Sandboxed page processes

## 0.2 — Daily browsing

- [x] Local bookmarks
- [x] Worldwide country and system-language localization
- [ ] Bookmark import
- [x] Searchable browsing history
- [x] Open-session restore
- [x] Closed-tab restore
- [x] Download center with live progress and file actions
- [ ] Per-site permission controls
- [x] Configurable search provider
- [x] HTML5 and embedded video-player fullscreen

## 0.3 — Privacy and reliability

- [x] EasyList/EasyPrivacy tracker and ad blocking
- [ ] Profile isolation and private windows
- [ ] Safe browsing checks
- [x] Native update checks, download progress, and restart-to-install
- [ ] Commercially signed update packages
- [ ] Crash recovery
- [ ] Signed Windows installer

## 0.4 — Productivity

- [ ] Opera-style workspaces
- [ ] Tab groups and vertical tabs
- [ ] Sidebar web apps
- [ ] Split-screen browsing
- [ ] Cross-device bookmark and tab sync
- [ ] Battery and memory saver modes

## 1.0 — Audited release

- [ ] Independent security review
- [ ] Stable migration and backup policy
- [ ] Windows and Linux production builds
- [ ] Accessibility and localization review
- [ ] Public threat model and privacy documentation
